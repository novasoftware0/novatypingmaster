# ⌨️ Nova Typing Master - User Help Guide

Welcome to **Nova Typing Master!**

Nova Typing Master is a typing practice application designed to help users improve their typing speed, accuracy, and keyboard skills through structured lessons, interactive games, and numeric keypad training.

---

## 1. Main Screen & Navigation

After opening the software, you will see the main screen. From here, you can select any lesson or typing game according to your learning needs.

## 2. Structured Lessons & Practice

Nova Typing Master provides different learning and practice options:

- **Home Row Lessons:** Learn the correct placement of your fingers.
- **Alphabet Practice:** Improve your typing skills with letters.
- **Numbers & Symbols:** Practice numbers and special characters.
- **Live Performance:** View your typing speed (WPM) and accuracy percentage in real time.
- **Virtual Keyboard:** Get visual guidance on which key and Shift key to press using the correct hand.

## 3. Entertaining Typing Games

### 🦁 Lion vs Goat Game

An exciting typing challenge where accurate typing moves your goat forward, while typing mistakes allow the chasing lion to get closer.

This game helps improve typing speed, accuracy, and concentration.

### 🎮 Falling Letter Arcade Game

Letters fall from the top of the screen. Type each letter before it reaches the bottom.

Correct typing earns points and triggers colorful visual effects.

## 4. Numeric Keypad Training

This dedicated mode helps users improve their number-entry speed and accuracy.

Practice digits efficiently using the numeric keypad within set limits.

## 5. Feedback & Support

Have suggestions or feedback?

Open the **Feedback** section, enter your subject and message, and submit it directly through the application.

Your registered email address is automatically detected and filled in.

## 6. Notice & Appeal System

To support fair use of the software, users can view details of any notice or warning assigned to their account.

If needed, users can submit an explanation or appeal directly to the administrator from within the application.
